# Defect log

Defects found by the team during manual testing, CI and the November 9 test run. The Nov 9 defects also appear in Harmanpreet's retest report [`test-evidence-2026-11-09/defects.md`](../test-evidence-2026-11-09/defects.md) (PR #6): DEF-001 = D-09, DEF-002 = D-10, BLK-001 / BLK-002 = D-11, DEF-003 = D-14. Each fixed defect also exists as a **Bug** work item in Azure DevOps with the same ID in the title, linked to its user story.

Severity: **High** = wrong or unsafe answer, failed requirement or blocked release; **Medium** = test or tooling failure with a workaround; **Low** = cosmetic.

Fixing commits come from `git log`; the PR is the pull request that brought the commit to `main`. Test IDs refer to `docs/MavAssist_Test_Cases.xlsx`.
